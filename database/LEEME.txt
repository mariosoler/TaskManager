Scripts de la base de datos TaskManager (SQL Server)
===================================================

Esta carpeta se copia al publicar la aplicación. El sitio web la bloquea (Web.config,
hiddenSegments): no se puede descargar desde el navegador.

Instalación nueva
-----------------
1. Crear una base de datos vacía llamada TaskManager.
2. Ejecutar sobre ella TaskManager.sql (esquema completo, ya incluye todas las migraciones):

   sqlcmd -S <servidor> -d TaskManager -E -i TaskManager.sql

Actualizar una base ya existente
--------------------------------
Las migraciones son idempotentes: se pueden repetir sin problema, así que en caso de duda se pueden
ejecutar todas. Dos formas:

a) Todas de una vez, con migraciones_todas.sql (todas las de la carpeta "migraciones", en orden):

   sqlcmd -S <servidor> -d TaskManager -E -b -i migraciones_todas.sql

b) Una a una, en orden (001, 002, ...), las de la carpeta "migraciones" que falten:

   sqlcmd -S <servidor> -d TaskManager -E -b -i migraciones\006_etiquetas.sql

migraciones_todas.sql se genera con GenerarMigracionesTodas.ps1 (está en el proyecto; no se publica)
y no se edita a mano.

Datos de demostración (opcional)
--------------------------------
demo\tablero_demo_aplicaciones.sql crea un tablero de ejemplo para un usuario ya registrado:

   sqlcmd -S <servidor> -d TaskManager -E -i demo\tablero_demo_aplicaciones.sql -v EmailPropietario="usuario@ejemplo.com"

Ninguno de estos scripts crea inicios de sesión ni contiene contraseñas. El acceso de la aplicación
(identidad del grupo de aplicaciones de IIS) se configura aparte: ver README.md del proyecto.
